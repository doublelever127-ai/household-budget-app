# 가계부 앱 MVP

한국어 사용자를 위한 개인 가계부 앱 MVP입니다. 월별 수입과 지출을 기록하고, 예산 사용률과 카테고리별 소비 흐름을 확인할 수 있도록 만든 React Native / Expo 기반 앱입니다.

현재 목표는 개인 사용과 주변 사용자 테스트가 가능한 수준의 MVP입니다. 클라우드 동기화나 백업 같은 배포용 고급 기능은 아직 포함하지 않았습니다.

## 주요 기능

- 거래 추가, 수정, 삭제
- 수입 / 지출 구분
- 월별 거래 관리
- 월별 총수입, 총지출, 잔액 계산
- 월별 예산 설정 및 예산 사용률 표시
- 예산 초과 경고
- 카테고리 추가, 수정, 삭제
- 기본 수입 / 지출 카테고리 제공
- 같은 타입 안에서 카테고리 중복 이름 방지
- 사용자가 삭제한 기본 카테고리가 앱 재실행 후 다시 생기지 않도록 처리
- 거래 목록 검색
- 통계 화면
  - 월별 수입 / 지출 비교
  - 카테고리별 지출 비중
  - 최근 3개월 지출 추이
- 샘플 데이터 생성
- 데이터 초기화
- AsyncStorage 기반 로컬 데이터 저장
- 화면 간 선택 월 공유
- 긴 거래 목록 대응을 위한 `FlatList` 사용
- 금액 입력 검증
- 날짜 입력 자동 포맷

## 기술 스택

- React Native
- Expo
- TypeScript
- React Navigation
- Zustand
- AsyncStorage
- date-fns
- Vitest
- ESLint / Expo lint

## 설치 방법

Node.js와 npm이 설치되어 있어야 합니다.

```bash
npm install
```

Windows PowerShell에서 실행 정책 문제로 `npm` 명령이 막히면 아래처럼 `npm.cmd`를 사용할 수 있습니다.

```bash
npm.cmd install
```

## 실행 방법

Expo 개발 서버를 실행합니다.

```bash
npm run start
```

웹에서 실행하려면 다음 명령을 사용합니다.

```bash
npm run web
```

Android 또는 iOS 실행 스크립트도 준비되어 있습니다.

```bash
npm run android
npm run ios
```

실제 기기 테스트는 Expo Go 또는 Expo 개발 환경을 사용해 진행하는 것을 권장합니다.

## 테스트 방법

계산 유틸과 store 일부 동작에 대한 단위 테스트가 포함되어 있습니다.

```bash
npm run test
```

현재 테스트는 다음 범위를 포함합니다.

- 월별 거래 필터링
- 수입 합계 계산
- 지출 합계 계산
- 잔액 계산
- 카테고리별 지출 요약
- 예산 사용률 계산
- 선택 월 상태 변경
- 카테고리 중복 방지
- 삭제된 기본 카테고리 재생성 방지
- 금액 입력 포맷 / 검증
- 날짜 입력 유틸

## 검증 명령

현재 `package.json` 기준으로 사용할 수 있는 검증 명령입니다.

```bash
npm run lint
npm run typecheck
npm run test
npx expo export --platform web --output-dir .expo-web-export-check
```

`npx expo export --platform web --output-dir .expo-web-export-check`는 웹 export가 가능한지 확인하는 검증 명령입니다. 생성되는 `.expo-web-export-check/` 폴더는 `.gitignore`에 포함되어 있습니다.

## 웹 배포 방법

GitHub Pages로 정적 웹 앱을 배포할 수 있습니다. 배포 명령은 Expo web export로 `dist/` 폴더를 만들고, `gh-pages` 브랜치에 업로드합니다.

```bash
npm run deploy
```

PowerShell에서 `npm` 실행이 막히면 아래처럼 실행할 수 있습니다.

```bash
npm.cmd run deploy
```

배포 후 GitHub 저장소의 `Settings > Pages`에서 배포 소스가 `gh-pages` 브랜치로 설정되어 있는지 확인합니다.

예상 웹 주소:

```text
https://doublelever127-ai.github.io/household-budget-app/
```

친구나 주변 사람에게 테스트를 부탁할 때는 이 주소를 공유하면 됩니다. 웹 배포 버전도 브라우저의 로컬 저장소를 사용하므로, 기기나 브라우저가 바뀌면 데이터가 공유되지 않습니다.

## 폴더 구조

```text
src/
  components/   공통 UI 컴포넌트
  constants/    기본 카테고리와 테마 상수
  navigation/   탭 / 스택 네비게이션
  screens/      화면 컴포넌트
  services/     로컬 저장소 접근 로직
  store/        Zustand 상태 관리와 테스트
  types/        TypeScript 타입 정의
  utils/        계산, 날짜, 포맷, 검증, 샘플 데이터 유틸
```

## 데이터 저장 방식

앱 데이터는 `@react-native-async-storage/async-storage`를 사용해 기기 로컬에 저장됩니다.

저장 대상은 다음처럼 분리되어 있습니다.

- 거래 내역
- 카테고리
- 예산
- 삭제된 기본 카테고리 ID 목록

앱을 다시 실행해도 데이터가 유지되도록 설계되어 있습니다. 단, 클라우드 동기화나 별도 백업 기능은 아직 없습니다.

## 데이터 관련 주의사항

이 앱은 데이터를 기기 로컬 저장소에 저장합니다. 앱 삭제, 기기 초기화, 저장소 삭제가 발생하면 저장된 거래 내역과 설정이 사라질 수 있습니다.

현재 버전은 클라우드 동기화와 데이터 백업 / 복원 기능을 제공하지 않습니다. 장기 사용을 위해서는 추후 백업 / 복원 기능을 추가하는 것을 권장합니다.

## 데이터 초기화 주의

설정 화면의 데이터 초기화 기능은 저장된 거래, 예산, 카테고리 데이터를 초기화합니다. 초기화 후에는 기존 데이터를 복구할 수 없습니다.

## 금액 입력 정책

금액은 저장 시 `number` 타입의 양의 정수로 변환됩니다. 콤마는 화면 표시와 입력 편의를 위한 값이며 저장 전 제거됩니다.

허용되는 입력:

- 양의 정수
- 콤마가 포함된 양의 정수

예:

```text
1000
1,000
12000
```

차단되는 입력:

- 빈 값
- 0
- 음수
- 소수점
- 문자
- 원화 기호
- 지수 표기

예:

```text
-100
+100
12.5
100원
₩1000
abc100
1e5
```

잘못된 금액은 다른 숫자로 조용히 변환하지 않고, 한국어 오류 메시지와 함께 저장을 막습니다.

## 날짜 입력 방식

거래 날짜는 `YYYY-MM-DD` 형식으로 입력합니다.

지원하는 입력 보조 기능:

- 숫자 입력 기반 자동 포맷
- 오늘 선택
- 선택 월 1일 선택
- 전날 / 다음 날 빠른 선택
- 잘못된 날짜 저장 방지

선택한 월이 현재 월이면 거래 추가 화면의 기본 날짜는 오늘입니다. 선택한 월이 현재 월이 아니면 해당 월의 1일을 기본값으로 사용합니다.

## 현재 지원하는 기능

- 개인 로컬 가계부 기록
- 월별 수입 / 지출 / 잔액 확인
- 월별 예산 설정
- 카테고리별 지출 확인
- 최근 거래 확인
- 거래 목록 검색과 필터
- 기본 카테고리 관리
- 샘플 데이터 생성
- 전체 데이터 초기화
- 웹 환경 export 검증 가능

## 아직 지원하지 않는 기능

아래 기능은 현재 MVP에 포함되어 있지 않습니다.

- 클라우드 동기화
- 데이터 백업 / 복원
- 앱 잠금
- 반복 거래 자동 등록
- CSV 내보내기
- 다크모드
- 실제 모바일 date picker

## 추후 개선 예정 기능

사용자 테스트 후 우선순위를 정해 개선할 후보입니다.

- JSON 백업 / 복원
- 앱 잠금 또는 PIN
- 반복 거래
- CSV 내보내기
- 실제 date picker 도입
- 접근성 추가 개선
- 실제 기기 테스트 확대

## 개발 상태

현재 상태는 MVP 기능 구현과 핵심 결함 수정이 완료된 단계입니다.

최근 검증 기준:

- `npm run lint` 통과
- `npm run typecheck` 통과
- `npm run test` 통과
- `npx expo export --platform web --output-dir .expo-web-export-check` 통과

개인 사용과 주변 사용자 테스트는 가능한 상태입니다. 앱스토어 수준의 실제 배포 전에는 실제 기기 테스트, 데이터 백업 정책, 개인정보 보호 기능을 추가로 검토하는 것을 권장합니다.
