# 개인정보처리방침

최종 업데이트: 2026년 4월 27일

`자산 가계부`는 개인의 거래, 예산, 카테고리, 자산, 부채 정보를 직접 기록하고 확인하기 위한 로컬 저장형 가계부 앱입니다.

## 1. 수집하는 정보

현재 버전의 앱은 별도 서버를 운영하지 않으며, 사용자가 입력한 데이터를 외부 서버로 전송하지 않습니다.

앱 안에서 사용자가 직접 입력할 수 있는 정보는 다음과 같습니다.

- 거래 내역: 유형, 금액, 날짜, 카테고리, 메모, 결제수단 또는 계좌명
- 예산 정보: 월간 총예산, 카테고리별 예산
- 카테고리 정보: 카테고리 이름, 유형, 색상
- 자산 정보: 자산 이름, 유형, 금액, 메모
- 부채 정보: 부채 이름, 유형, 잔액, 금리, 메모
- 순자산 스냅샷: 월별 총자산, 총부채, 순자산

## 2. 데이터 저장 방식

입력한 데이터는 사용자의 기기 로컬 저장소에 저장됩니다. 현재 버전은 클라우드 동기화, 서버 백업, 계정 로그인을 제공하지 않습니다.

앱 삭제, 기기 초기화, 브라우저 저장소 삭제, 앱 데이터 삭제가 발생하면 저장된 데이터가 사라질 수 있습니다.

## 3. 데이터 공유

현재 버전은 사용자가 입력한 가계부 데이터를 제3자에게 판매하거나 공유하지 않습니다. 또한 광고 SDK, 분석 SDK, 소셜 로그인 SDK를 사용하지 않습니다.

## 4. 데이터 삭제

앱의 `더보기 > 데이터 초기화` 기능을 사용하면 앱에 저장된 거래, 예산, 카테고리, 자산, 부채 데이터를 초기화할 수 있습니다.

초기화 후에는 기존 데이터를 복구할 수 없습니다.

## 5. 보안 안내

현재 버전은 앱 잠금, PIN, 생체 인증, 암호화 백업 기능을 제공하지 않습니다. 금융 계좌 비밀번호, 주민등록번호, 카드 전체 번호, 인증번호와 같은 민감한 인증 정보는 메모나 이름 입력란에 저장하지 않는 것을 권장합니다.

## 6. 미성년자 이용

이 앱은 일반적인 개인 예산 관리를 위한 도구입니다. 보호자가 필요한 사용자는 보호자의 안내에 따라 사용하는 것을 권장합니다.
