# Google Play 출시 준비 체크리스트

최종 업데이트: 2026년 4월 27일

이 문서는 `자산 가계부`를 Google Play에 실제 출시할 때 확인해야 할 항목을 정리한 문서입니다.

| 항목 | 현재 상태 | 판단 |
|---|---|---|
| Android 패키지명 | `com.doublelever127.householdbudget` | 준비됨 |

## 2. 출시 전 필수 작업

1. Expo 계정과 EAS CLI를 준비한다.
2. Android 프로덕션 빌드를 생성한다.
3. Google Play Console에서 앱을 만든다.
4. 개인정보처리방침을 웹에서 접근 가능한 URL로 게시한다.
5. Play Console의 Data safety 항목을 작성한다.
6. 콘텐츠 등급 설문을 작성한다.
7. 스토어 등록정보를 작성한다.
8. 실제 Android 기기에서 내부 테스트를 진행한다.
9. 개인 개발자 계정 조건에 해당하면 폐쇄 테스트를 진행한다.
10. 심사 제출 전 앱 내 데이터 초기화와 개인정보 안내가 보이는지 확인한다.

## 3. 빌드 명령

EAS CLI가 설치되어 있지 않다면 먼저 설치한다.

```bash
npm install -g eas-cli
```

Expo 계정에 로그인한다.

```bash
eas login
```

프로젝트를 EAS에 연결한다.

```bash
eas init
```

Android 테스트용 APK를 만든다.

```bash
eas build --platform android --profile preview
```

Google Play 제출용 AAB를 만든다.

```bash
eas build --platform android --profile production
```

## 4. Play Console에서 주의할 점

### Data safety

현재 앱은 서버로 데이터를 전송하지 않는 로컬 저장형 앱으로 설계되어 있다. Play Console 작성 시 실제 앱 동작과 다르게 과장하거나 축소해서 적으면 안 된다.

확인할 내용:

- 앱이 사용자 입력 데이터를 외부 서버로 보내지 않는가?
- 광고 SDK, 분석 SDK, 소셜 로그인 SDK를 사용하지 않는가?
- 사용자가 앱 안에서 데이터를 초기화할 수 있는가?
- 개인정보처리방침에서 로컬 저장과 데이터 삭제 방법을 설명하는가?

### 금융 정책

이 앱은 예산, 지출, 자산, 부채를 사용자가 직접 기록하는 개인 관리 도구다. 대출 중개, 투자 자문, 수익 보장, 금융상품 판매 기능은 제공하지 않는다.

스토어 설명에서도 다음 표현은 피한다.

- 확정 수익을 보장하는 표현
- 투자 종목 추천으로 보일 수 있는 표현
- 대출 승인 또는 금융상품 중개로 보일 수 있는 표현
- 사용자의 금융 계정과 자동 연동된다는 표현

### 앱 접근

로그인이 없는 앱이므로 심사자가 바로 접근할 수 있다. 단, 빈 화면만 보이면 기능을 이해하기 어려우므로 `더보기 > 샘플 데이터 생성` 기능을 설명란 또는 심사 메모에 적는 것을 권장한다.

## 5. 스토어 등록정보 초안

### 짧은 설명

수입, 지출, 예산, 자산 흐름을 한눈에 확인하는 로컬 저장형 가계부 앱

### 긴 설명 초안

`자산 가계부`는 개인의 월별 수입과 지출을 기록하고, 예산 사용률과 순자산 흐름을 확인할 수 있는 가계부 앱입니다.

주요 기능:

- 거래 추가, 수정, 삭제
- 월별 수입, 지출, 잔액 확인
- 예산 설정과 사용률 확인
- 카테고리별 지출 분석
- 자산과 부채 직접 입력
- 순자산 스냅샷 저장
- 최근 거래와 월별 분석 확인
- 샘플 데이터 생성과 데이터 초기화

현재 버전은 데이터를 기기 로컬 저장소에 저장합니다. 클라우드 동기화, 금융기관 자동 연동, 투자 추천, 대출 중개 기능은 제공하지 않습니다.

## 6. 실제 기기 테스트 체크리스트

- 앱 설치 후 첫 화면이 정상 표시되는가?
- 첫 거래 추가가 가능한가?
- 금액 `12000` 입력 시 `12,000`으로 표시되는가?
- `-100`, `12.5`, `100원`, `1e5`가 저장되지 않는가?
- 예산 설정과 예산 사용률이 정상 표시되는가?
- 자산과 부채를 추가할 수 있는가?
- 순자산 스냅샷을 저장할 수 있는가?
- 앱을 완전히 종료했다가 다시 켜도 데이터가 유지되는가?
- 데이터 초기화 전 확인 메시지가 표시되는가?
- 큰 글씨 설정에서 주요 버튼과 금액이 잘리지 않는가?
- 오프라인 상태에서도 앱의 핵심 기능이 동작하는가?
